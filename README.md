# 外文姓名譯名快速查詢系統 (Google Sheets 26 分頁整合版)

這是一個基於 Google Sheets 資料庫的外文姓名、中文譯名與四角號碼查詢系統，支援全庫 26 個字母分頁（A ~ Z）整合搜尋與單一分頁快速切換。

- **資料庫來源**：[Google 試算表連結](https://docs.google.com/spreadsheets/d/1DprJwhRdYzm_5icKpEAEZ1pOO-v22eCNrJi1EWfj9HA/edit)
- **涵蓋範圍**：全 26 個字母子工作表（A ~ Z）
- **總收錄筆數**：共 40,061 筆譯名資料

---

## ✨ 主要功能特色

1. **📚 全庫 4 萬筆跨分頁即時搜尋**：
   - 支援雙向中英文全文模糊查詢、多關鍵字以空白分隔搜尋。
   - 搜尋字詞自動以鮮明黃色螢光高亮標記。

2. **🔤 A - Z 快速分頁切換**：
   - 點擊頂部分頁按鈕（`全部分頁` 或 `A` ~ `Z`），可隨時切換至單一字母分頁或進行全庫搜尋。

3. **📊 4 大即時統計指標卡片**：
   - 頂部顯示「總資料庫筆數」、「目前符合筆數」、「當前分頁筆數」、「已載入分頁數」。

4. **🔄 雙檢視模式（表格模式 / 卡片網格）**：
   - **表格模式**：高對比度排版，包含所屬分頁徽章、外文原名（加粗深藍）、中文譯名與四角號碼標籤。
   - **大卡片模式**：適合大螢幕與視覺化瀏覽，每筆資料獨立卡片呈現。

5. **🔍 彈出式資料明細與一鍵複製**：
   - 點選任一列或卡片即可彈出視窗查看完整欄位內容，並支援一鍵複製到剪貼簿。

6. **📁 多格式資料匯出**：
   - 支援將篩選後的查詢結果匯出為 **CSV 檔案**、**JSON 檔案**，或直接複製為表格文字。

7. **👁️ 自由調整字體大小**：
   - 頂部導覽列提供 **【 預設 / 大字體 / 特大字體 】** 即時縮放切換。

8. **⚡ Google Visualization JSONP 跨網域引擎**：
   - 無需後端伺服器，直接於前端跨域串流讀取 Google 試算表，支援 GitHub Pages 免費靜態託管部署。

## 🚀 本地執行方式

### 方式一：直接以瀏覽器開啟
直接雙擊 [`index.html`](index.html) 檔案，使用 Chrome、Edge、Firefox 等瀏覽器即可直接使用。

### 方式二：使用本地 HTTP 伺服器
```bash
# 使用 Python 內建伺服器
python -m http.server 8080

# 或使用 npx serve
npx serve .
```
接著於瀏覽器造訪 `http://localhost:8080`。

## 🌐 GitHub Pages 部署方式

1. 將本專案推送到 GitHub 倉庫 `trans_name`。
2. 進入 GitHub 倉庫的 **Settings** > **Pages**。
3. 在 **Branch** 選擇 `main` 分支並選擇根目錄 `/ (root)`，點擊 **Save**。
4. 幾分鐘後即可透過 `https://<你的GitHub帳號>.github.io/trans_name/` 於公開網路直接存取！
